# Night Shift City — pixel hangout

An original browser hangout inspired by the *setup* of voidcity.live's game: a club hub, tent city, apartments, a walkable avatar, chat bubbles and wandering NPCs.

Everything is written from scratch (canvas, no dependencies). The map, art and music are generated in code, and no code or assets from the source game are included. It is single-player: NPCs are local, and there is no server or accounts.

Run it: open `index.html`, or `python3 -m http.server` in this folder.
Controls: WASD/arrows or click to move, Enter to chat.
