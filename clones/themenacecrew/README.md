# Menace Crew — MENACE OS 98 (fan rebuild)

A static rebuild of the *concept* behind themenacecrew.com: a Windows 98 style desktop with draggable windows, taskbar, Start menu, boot screen, CRT/sound toggles, and a soundboard.

Code is written from scratch. All text, products and links are placeholders; the original site's lore, artwork and assets are not included.

Run it: open `index.html`, or `python3 -m http.server` in this folder.
